# 🏢 Sistema Inventario GAD

Sistema administrativo desarrollado en **C# + WPF** para control de inventario, bienes institucionales y movimientos internos.

---

## 🚀 Funcionalidades

✅ Gestión de bienes institucionales  
✅ Inventario de productos  
✅ Control de movimientos  
✅ Gestión de ubicaciones  
✅ Reportes PDF  
✅ Fotografías de activos  
✅ Sistema de usuarios y autenticación  
✅ Dashboard administrativo  

---

## 🛠️ Tecnologías utilizadas

- C#
- WPF
- XAML
- Entity Framework Core
- SQLite
- QuestPDF

---

## 📂 Arquitectura

El proyecto está organizado por capas:

```text
InventarioUI/
InventarioSimple/
Services/
Models/
Views/
Utils/
```
